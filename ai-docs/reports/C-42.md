## What changed
- **Strings files deleted**: the 11 `lib/core/design_system/widgets/**/*_strings.dart` files (68 key constants). Every use is now `LocaleKeys.<group>_<key>` (generated, D-037), in the same widget folders. 33 files changed in total, including tests that used the old constants.
- **Permission copy**: `permissions_strings.dart` built title and message keys from the `AppPermission` name. They are now two exhaustive `switch`es in `permission_rationale_dialog.dart` (`_titleKey`, `_messageKey`). A new `AppPermission` value fails to compile until it has copy.
- **Literal calls**: `app_shell.dart` and `home_page.dart` used `'app_nav.home'.tr()` and `'app_nav.more'.tr()`. Now `LocaleKeys.app_nav_home` / `app_nav_more`.
- **Unused key**: `app_nav.continue` removed from `en.json` and `ar.json` (it was used only by the C-11 onboarding stub, which C-18 replaced).
- **Barrel doc**: `widgets.dart` no longer mentions `*_strings.dart`.
- **Generated**: `lib/generated/*` regenerated (D-037); build_runner run.
- **Guard test**: `test/translations/no_literal_keys_test.dart`. It scans every `.dart` file under `lib/` (except `*.g.dart` and `lib/generated/`) for a `.tr()` or `.plural()` call on a string literal, or `.plural('…'`. The test fails with `file:line` for each hit. A self-test on inline samples checks the pattern catches the three literal forms and accepts `LocaleKeys` calls.
