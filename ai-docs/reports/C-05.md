# C-05 — design_system: tokens, theme, responsive

Worker A · branch `worker-a` · worktree `../riverpod_core-a`

## What changed
- **Tokens** (`lib/design_system/tokens/`): one brand file (`brand_config.dart`, seed `0xFF4A6FA5`, `brandFontFamily = null`). Spacing, radius, elevation, durations as const value classes. Semantic colors `success / warning / info` (each with `on*` and `*Container`, light and dark sets). `AppTokens` is the `ThemeExtension` that carries them. Type scale is Material 2021 `Typography` colored from the scheme and the brand font.
- **Theme** (`lib/design_system/theme/`): `buildLightTheme()` / `buildDarkTheme()` from `ColorScheme.fromSeed(brandSeedColor)`. Dark uses the dark tonal palette, not inverted light colors. `context.tokens` in `theme_context.dart`.
- **Responsive** (`lib/design_system/responsive/`): `AppBreakpoint { phone < 600, tablet 600–1023, desktop ≥ 1024 }`, `context.breakpoint`, `context.isLandscape`, `ResponsiveLayout(phone, tablet?, desktop?)` (falls back to the smaller layout), `maxContentWidth = 720`, `clampTextScale()` clamping the system scale to 0.8–2.0.
- **main.dart**: removed `ResponsiveScaledBox` and the fixed `TextScaler.linear(1)`. The builder now clamps the system text scale. Uses `buildLightTheme()` / `buildDarkTheme()`. `ResponsiveBreakpoints` is still in place because `lib/core/mixins/alert_utils.dart` calls `ResponsiveBreakpoints.of(context)`; it goes with C-09.
- **Deleted**: `lib/core/themes/app_colors.dart`, `lib/core/themes/style.dart`, `lib/core/widgets/custom_button.dart`, `lib/core/widgets/my_text_filed.dart`, `lib/core/mixins/scaffold_messeneger.dart` (zero importers), `test/smoke_test.dart` (see Decisions).
- **help_functions.dart**: `showSnackBar` now takes its colors from the new tokens (import change plus color source only).
- **ai-docs/TASKS.md**: C-05 status set to REVIEW.

## Decisions made
- **Seed `0xFF4A6FA5`** (muted steel blue). Owner-approved as the neutral default. One-file change in `brand_config.dart`.
- Light/dark schemes come from `ColorScheme.fromSeed`, so M3 tonal roles and error colors are generated, not hand-picked. Only the success/warning/info accents are hand-set (both themes).
- `AppTokens.lerp` switches at t = 0.5. Scales are not interpolated.
- `context.tokens` asserts in debug if the theme lacks `AppTokens`, then throws on null in release.
- `help_functions.dart` error color = `ColorScheme.fromSeed(seedColor: brandSeedColor).error`, because a plain function has no `BuildContext`. This is a legacy helper; C-09 replaces it with `AppSnackbar`.
- `responsive_framework` stays in `pubspec.yaml` (alert_utils.dart still imports it). `ResponsiveBreakpoints` stays in `main.dart` for the same reason.
- `lib/main.dart` was edited, not deleted (owner-confirmed; C-08 deletes it).
