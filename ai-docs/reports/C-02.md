# C-02 — AppConfig and flavors

Worker B · branch `worker-b` · worktree `../riverpod_core-b`

## What changed
- `AppConfig` (typed, validated) loaded from `--dart-define-from-file` keys.
  - `AppConfig.fromEnvironment()` is the only place that reads defines (`String.fromEnvironment`).
  - `AppConfig.fromMap(Map<String,String>)` does parsing and validation. Empty values count as missing.
  - All problems are collected and thrown together as `ConfigException`.
  - `ensureFlavor(Flavor entrypoint)` throws on a FLAVOR / entrypoint mismatch (D-018).
- `Flavor { dev, staging, prod }` and `LogLevel { debug, info, warning, error, off }` in their own files.
- `appConfigProvider` (`@Riverpod(keepAlive: true)`) throws `UnimplementedError` until bootstrap (C-08) overrides it.
- `env/*.example.json` for dev, staging and prod, with placeholder values only. Real `env/*.json` is git-ignored.

## Decisions made or needed
Approved by the Lead (answers to the questions sent before implementation):
- Keys: `FLAVOR`, `APP_NAME`, `API_BASE_URL`, `CONNECT_TIMEOUT_MS`, `RECEIVE_TIMEOUT_MS`, `LOG_LEVEL`, `ENABLE_CRASH_REPORTING`, `ENABLE_ANALYTICS`, `CRASH_DSN`. Timeouts are in milliseconds.
- Required: FLAVOR, APP_NAME, API_BASE_URL, both timeouts.
- Optional defaults:
  - LOG_LEVEL: dev `debug`, staging `info`, prod `warning`.
  - ENABLE_CRASH_REPORTING: dev `false`, staging and prod `true`.
  - ENABLE_ANALYTICS: `false`.
  - CRASH_DSN: null.
- Bool keys accept only the literal `true` or `false`.

Choices made in this task (for the Lead to confirm in review):
- `fromEnvironment()` reads every key with `String.fromEnvironment`, not `bool`/`int.fromEnvironment`. Reason: a missing key arrives as `''`, which lets `fromMap` report it together with other problems. Typed parsing is still done once in `fromMap`.
- `API_BASE_URL` must be an absolute `http` or `https` URL. `https` is required for staging and prod. Dev may use `http` for a local backend.
- `CRASH_DSN` is only checked to be non-empty when set. No URL validation, since the crash vendor is not chosen yet (C-30).
- `ensureFlavor` is an instance method on `AppConfig`.
- `apiBaseUrl` is stored as a `String`. Dio takes a string base URL.
- The `.g.dart` file is committed as the Lead required.
