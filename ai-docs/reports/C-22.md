# C-22 — Share, external links, in-app review, app version page

Worker S4, branch `worker-v`.

## What changed
- `ShareService` (`core/sharing`): `shareText`, `shareLink` (http/https only), `shareFile`. Returns bool, never throws. Backend seam `ShareBackend`, plugin `share_plus` imported only there.
- `ExternalLinks` (`core/links`): `openUrl`, `openMail`, `openPhone`, `openStore`. Scheme allow-list http/https/mailto/tel (web links also need a host); returns bool, never throws. Mail query is percent-encoded by hand (no `+` for spaces). Backend seam `LinkBackend` over `url_launcher`. `lib/core/mixins/url_launcher.dart` deleted (grep: nothing imported it).
- `ReviewService` (`core/review`): `maybeAskForReview()` shows the in-app prompt at most once per `minInterval` (default 90 days, last time kept in prefs as a string list under the device key `review.lastAskedAt`, injected clock); falls back to the store listing when the in-app prompt is unavailable. `openStoreListing()` is the unthrottled path for the "Rate the app" button.
- `AppInfo` + `appInfoProvider` (`core/app_info`): name, version, build number, package name, `versionLabel`. Source seam over `package_info_plus`.
- `AboutPage` (`features/more`, `/about`): name, version, build, flavor (dev/staging only), licenses (`showLicensePage`), share and rate buttons; uses `AsyncValueView` (loading skeleton, error + retry). `MorePage` got an About tile (logout kept).
- Platform: Android `<queries>` (https, http, mailto, tel); iOS `LSApplicationQueriesSchemes`.
- Translations: `more.entry.*`, `more.about.*` in ar and en; `lib/generated/*` regenerated.

## Decisions made or needed
- NEEDED (blocking the link at runtime): the route for `/about` must be registered in `lib/core/router/routes.dart`, which C-21 owns and my task did not list. `MorePage` navigates with `context.push(AboutPage.routeName)`. The Lead must add, then run build_runner:
  ```dart
  @TypedGoRoute<AboutRoute>(path: AboutPage.routeName)
  class AboutRoute extends GoRouteData with $AboutRoute {
    const AboutRoute();
    @override
    Widget build(BuildContext context, GoRouterState state) => const AboutPage();
  }
  ```
  (`MorePage` can then use `const AboutRoute().push<void>(context)`; the string push keeps working.) Also decide whether `/about` sits inside or outside the shell and whether auth redirect rules need it.
- Added `appStoreIdProvider` (null by default, an app overrides it) so the review store-listing fallback has the iOS App Store id; no config key was added because `AppConfig` is outside this task.
- `ShareService.shareLink` shares a `Uri` (not text) so iOS shows a link preview; `share_plus` forbids text and uri together.
- The About share message is `more.about.shareMessage` ("Check out {app name}"); no store link is included because no store URL exists in config yet.
- `notification_providers.dart` still imports `url_launcher` directly (C-20 file, not in this task); it could use `ExternalLinks` later.
