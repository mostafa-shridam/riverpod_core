# C-23 — Permissions and media

Worker N · branch `worker-n`

## What changed
- `lib/core/permissions/`: `AppPermission {camera, photos, microphone}`, `AppPermissionResult {granted, denied, permanentlyDenied, restricted, limited}` (+ `isUsable`), `PermissionBackend` (injectable interface) with `PermissionHandlerBackend` over `permission_handler`, `PermissionService` (`status`, `request`, `ensure(permission, context)`), providers `permissionBackendProvider`, `permissionRationalePresenterProvider` (null by default), `permissionServiceProvider` (all keepAlive).
- `ensure` flow: granted/limited/restricted return as is; denied shows the rationale first only when the system advises it (`shouldShowRationale`) and a presenter is wired, then the system prompt; permanently denied shows the rationale with "Open settings" and opens the settings on accept (result stays `permanentlyDenied`, re-check with `status` on resume). `context.mounted` is checked after every await.
- `lib/core/media/`: `MediaService` (`pickImage(source, crop, maxWidth=1920, quality=85, cropStyle)`, `pickMultiImage`, `pickVideo`, `pickFile(types)`), backends `MediaPickerBackend` (image_picker + file_picker), `ImageCropperBackend` (image_cropper), `ImageCompressorBackend` (flutter_image_compress), `PickedMedia(path, size, mimeType)`, `mimeTypeOfPath`, `ImageCropStyle.fromTheme(ThemeData)` (crop screen colors from the design-system theme). Cancel returns null (empty list for multi); failures throw `AppException` (`PlatformException` `*_access_denied` -> `ForbiddenException`, otherwise `mapError`); compression failure -> `UnknownException`.
- Pipeline: picker caps the longest side at `maxWidth` -> optional crop -> JPEG re-encode at `quality` into the cache dir (original untouched). Video and files are returned as is.
- `lib/core/design_system/widgets/permissions/`: `PermissionRationaleDialog` (composed from `AppDialogFrame`, icon per permission, Allow/Open settings + Not now, label overrides), `showPermissionRationale` (a `PermissionRationalePresenter`), `permissions_strings.dart`.
- Strings: `ds_permissions` appended to `ar.json` and `en.json`. `lib/generated/*` NOT regenerated.
- Deleted `lib/core/mixins/image_picker.dart` (zero importers).
- Android: `CAMERA` permission, `uses-feature camera required=false`, `UCropActivity` (required by image_cropper). No storage permission; gallery uses the system photo picker. iOS: `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`, `NSMicrophoneUsageDescription` (generic English sentences, no placeholders).
