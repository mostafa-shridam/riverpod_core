## Decisions made or needed
Choices made in this task, for the Lead to confirm in review:
- **iOS bundle id:** the script uses the same `--id` as Android for `PRODUCT_BUNDLE_IDENTIFIER`, and `<id>.RunnerTests` for the test target. The template's iOS id (`com.example.riverpodCore`) differs from its Android id, and after the rename they match.
- **`CFBundleName`:** set to the Dart package name, matching the template's existing value (`riverpod_core`).
- **`--id` format:** lowercase letters and digits, at least two segments, no underscores. Underscores are rejected because iOS bundle ids do not allow them. This is stricter than Android alone.
- **`--name` format:** letters, digits, spaces, `.`, `_` and `-` only. This keeps the values safe to insert into XML, Gradle and YAML without escaping.
- **Already-renamed trees:** a request whose name, id and package all match the current tree exits with code 1 and says nothing to rename. The spec said both "refuse" and "second run is a no-op"; a refusal with no writes satisfies both.
- **Web:** the spec lists `web/index.html` and `web/manifest.json`, but D-022 removed web from the template, so the folder does not exist. The script handles them only if present, and it does not yet know what to replace in them. Not implemented; the Lead should decide whether to add them when web returns.
- **`--package` default:** derived from the name, with a `app_` prefix for names that start with a digit.

## Round 2 — fixes for the Lead's CHANGES (directives_ordering)

Problem: after a real rename, `flutter analyze` reported 23 `directives_ordering` issues. Rewriting `package:riverpod_core/` to a new name changes the alphabetical order of import blocks.

What changed:
- `rewriteDartImports` now re-sorts the directives of a file whenever its package imports changed. `sortDirectives` sorts each run of consecutive single-line `import` (or `export`) lines: `dart:` first, then `package:`, then relative, each alphabetical by URI. Blank lines, comments, `part` and other lines end a run and stay in place. The sort is idempotent.
