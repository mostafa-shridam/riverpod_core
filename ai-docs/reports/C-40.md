# C-40 — Wire easy_localization defaults and provider retry policy into bootstrap

## What changed
- `bootstrap.dart`: `EasyLocalization(saveLocale: true, ignorePluralRules: false, fallbackLocale: en)`, no `startLocale` (saved locale, else device locale if supported, else `en`; D-035). Removed the `getLanguageCodeHelper` import and use. `await initFormatting()` before `runner`. Root `ProviderContainer(retry: (retryCount, error) => null)` (D-032).
- `pump_app.dart`: `ignorePluralRules: false` explicit.
- `STATE_AND_DATA.md`: replaced the internal `copyWithPrevious` pattern. Verified against riverpod 3.4.3 source and an experiment: assigning `AsyncLoading<T>()` to a notifier `state` keeps the previous value (`hasValue` true, `isReloading` true); the next `AsyncError` also keeps it.
- `app.dart`: no change needed (already uses `context.locale`).
