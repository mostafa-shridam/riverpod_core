## Decisions made or needed
- `AppBottomNavBar` renders a rail on tablet/desktop, but a rail must sit beside the content, so `AppScaffold.navigationBar` places it (bottom bar on phone, rail in a Row on wide screens). Used outside `AppScaffold` on a wide window it still renders as a rail and the caller lays it out (documented in the class doc).
- `AppAvatar` initials use `FittedBox` instead of a fixed text scaler (CONVENTIONS forbids fixed `textScaler`).
- Component dimensions with no token (avatar diameters 24..80, list tile min height 56, accordion min height 56, stepper marker 32, tab heights 48/72) are private constants in the widget files. Question for the Lead: should a "component size" token group be added later?
- Goldens use the flutter_test Ahem font, so text and Material icons render as blocks. Layout, color and RTL are verifiable; glyph shapes are not.
