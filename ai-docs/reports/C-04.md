## Decisions made
- **In-memory translations**: `pumpApp` uses the generated `CodegenLoader` (the same loader `main.dart` uses), not the JSON assets. The parity test reads the JSON files directly, so a stale generated loader would not be caught here. C-03 regenerates it via `build.sh`.
- **No platform channels in tests**: `SharedPreferences.setMockInitialValues({})` before `EasyLocalization.ensureInitialized()`, run through `tester.runAsync` so the real async load does not hang under the fake clock.
- **Fresh localization per `pumpApp` call**: `EasyLocalization` reads `startLocale` only in `initState`. `pumpApp` unmounts with `SizedBox()` first, so a second call with another locale really applies it.
- **`Override` import**: `Override` is taken from `package:flutter_riverpod/misc.dart` (not exported by the main barrel in Riverpod 3.4.3).
- **`TextDirection` clash**: `easy_localization` re-exports intl's `TextDirection`; the test imports it with `hide TextDirection`.
