## Decisions needed (Lead to record)
**Digit policy proposal.** Latin digits (0-9) and ASCII separators (`.` `,` `%`) for numbers and dates in BOTH languages by default (intl's `ar` output is normalised to this). A `useArabicIndicDigits` setting switches Arabic-locale output to Arabic-Indic digits; it never affects English. Why: consistent with prices/IDs/phone numbers, copy-paste and search work, and users can opt in. Rejected: always Arabic-Indic (breaks numeric consistency).
Open point: persisting `useArabicIndicDigits` needs a `PrefKeys`/`PrefsStorage` field in `lib/core/storage/prefs_storage.dart` (C-06, not in C-12's file list). The formatter parameter is implemented and tested; `appFormattersProvider` currently passes `false`. A follow-up task must add the pref and wire it into `appFormattersProvider`.

## Wiring notes for bootstrap / app (C-08)
1. Before `runApp`: `await EasyLocalization.ensureInitialized(); await initL10nFormatting();` and load prefs: `final prefs = await container.read(prefsStorageProvider.future)` (or equivalent).
2. Start locale: `final start = resolveStartLocale(saved: prefs.locale, deviceLocales: PlatformDispatcher.instance.locales);`
3. `EasyLocalization(supportedLocales: supportedLocales, path: translationsPath, assetLoader: const CodegenLoader(), fallbackLocale: const Locale('en'), startLocale: start, saveLocale: false, ignorePluralRules: false, child: ...)`.
   - `saveLocale: false` because `PrefsStorage` is the single source of truth.
   - `ignorePluralRules: false` is REQUIRED; with the package default (`true`) Arabic few/many/zero never apply.
4. In `MaterialApp.router`: `locale: context.locale`, `supportedLocales: context.supportedLocales`, `localizationsDelegates: context.localizationDelegates` (already how main does it).
5. Language switcher: `changeAppLocale(context, ref.read(localeControllerProvider.notifier), Locale('ar'))`. UI updates without restart; choice survives restart via prefs.
6. User-facing numbers/dates: `ref.watch(appFormattersProvider)`; plurals: `pluralText(LocaleKeys.l10n_itemsCount, n, formatters: f)`.
