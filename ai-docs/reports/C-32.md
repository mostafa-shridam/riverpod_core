# C-32 report — selection and form controls

## What changed
Added the `selection/` widget family in `lib/core/design_system/widgets/selection/`: `AppFormField<T>` (label + helper/error chrome, a real `FormField`, controlled: follows the parent `value`), `AppCheckbox`, `AppSwitch`, `AppRadioGroup` (Flutter `RadioGroup`), `AppDropdown` (always via `AppSelectionSheet`; `searchable` adds the search box), `AppSegmentedControl` (own pill implementation, labels wrap at 2.0x, check on the selected segment), `AppSlider` + `AppRangeSlider`, `AppDateField`, `AppTimeField` (platform pickers, `MaterialLocalizations` formatting so ar digits/names), `AppRating`, `AppChipGroup` (single/multi, built on `AppChip`), plus the building block `AppPickerField` (looks like `AppTextField`, opens a picker).
All controls take value + onChanged (null = disabled), `validator`, `errorText` (server error), `enabled`, and work inside `Form` (validate/save/reset).
Strings: `selection_strings.dart`, keys under `ds_selection` in ar.json/en.json (D-023); generated files untouched.
