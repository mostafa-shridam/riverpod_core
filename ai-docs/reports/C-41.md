# C-41 — Storage on hive_ce (remove shared_preferences and Drift)

Status: REVIEW. Worker B, branch `worker-b`. Merged with `main` at `583dfa7`.

## What changed

- **Packages.** Added `hive_ce` 2.22.0 and `hive_ce_flutter` 2.5.0. Removed `shared_preferences`, `drift`, `drift_flutter` and `drift_dev` from direct dependencies. `shared_preferences` is still in the lock file as a transitive dependency of `easy_localization`; no code under `lib/`, `test/` or `tool/` imports it (see the grep proof below).
- **Licence.** `hive_ce` 2.22.0 ships a `LICENSE` file containing BSD-3 text and Apache-2.0 text. Both are permissive. The D-034 wording was corrected on `main` to match (`bafd009`).
- **Boxes.** `lib/core/storage/hive_boxes.dart` defines `settingsBox` (`Box<dynamic>`) and `cacheBox` (`Box<Map<dynamic, dynamic>>`) as keepAlive providers. `openAppStorage()` in `lib/core/bootstrap/bootstrap.dart` calls `Hive.initFlutter()`, opens both boxes and returns the overrides. Bootstrap opens storage after config and before the container; a storage failure is fatal and goes to the zone error handler.
- **`PrefsStorage`** (`lib/core/storage/prefs_storage.dart`) sits on the settings box. Its provider is still async (`prefsStorageProvider` is a `FutureProvider`), so existing `.future` and `.value` callers are unchanged. The locale field is not stored here (D-035; easy_localization persists it).
  - Typed accessors added: `appLockEnabled` / `setAppLockEnabled` (`settings.appLock`, `['1']` or `[]`), `disabledNotificationChannels` / `setDisabledNotificationChannels` (`user.notifications.disabledChannels`), `collectionConsent` / `setCollectionConsent` (`settings.collectionConsent`, null until chosen), `dismissedUpdateVersions` / `setDismissedUpdateVersions` (`app.remoteConfig.dismissedUpdates`, the same slot `DismissedUpdates` uses).
  - The generic `getStringList` / `setStringList` slot stays.
- **Cache.** `lib/core/storage/cache/cache_store.dart` is `CacheStore` over the cache box, with the C-16 operations. Each entry holds `savedAt`, `lastAccessedAt`, `etag`, `ttl` and `maxAge` (D-038). It lists and deletes by age (`keysSavedBefore`, `deleteSavedBefore`) and by least-recent access (`keysLeastRecentlyAccessed`, `deleteLeastRecentlyAccessed`). `CachedRepositoryHelper` keeps the C-16 behaviour and records access on each hit.
- **Logout.** `clearUserData` takes `cache: CacheStore` instead of the database.
- **Consent.** `lib/core/firebase/collection_consent.dart` no longer uses `SharedPreferences`; it reads and writes through `PrefsStorage`.
- **Removed.** `lib/core/storage/database/**` (drift `AppDatabase`) and its test.

## Decisions

- `defaultMaxAge` is 30 days and `CacheStore.write` defaults `ttl` to one hour. These are interim values; policy presets belong to C-44.
- Pruning, policy presets and the revalidate/no-op logic are not built here (C-44).
- Typed accessors wrap the existing key formats, so callers that still use the generic slot keep working.
- The soft-update dismissal accessor shares its key with `DismissedUpdates`. The feature code still uses the generic slot; migrating it is a follow-up.

## Tests

- Test storage is in memory by default (`Hive.openBox(..., bytes: Uint8List(0))`), so widget tests do no file I/O. Reopen tests use `testStoragePath()`, a temp directory removed after the test.
- `test/flutter_test_config.dart` answers the `shared_preferences` platform channel for every test. easy_localization reads it in `EasyLocalization.ensureInitialized`. This keeps the package out of test code.
- Ported: prefs, clear-user-data, cache helper, bootstrap, session, notification, remote-config, startup, router, firebase bootstrap and device-info tests. The database tests are replaced by `test/core/storage/cache_store_test.dart`. No test was dropped.

## Known gaps

- A storage failure in bootstrap is fatal, but it is not reported to the crash reporter, because the container (and its reporter) is built after storage opens.
- `constants.dart` stays. Bootstrap, `pump_app.dart` and two router/more tests still import `supportedLocales`, `translationsPath` and friends, so it cannot be removed yet.
- easy_localization still pulls `shared_preferences` in transitively.
- `DismissedUpdates` (feature code) does not yet call the typed accessor.
