# C-06 — Storage: prefs, secure storage, Drift DB; remove Hive

Worker A · branch `worker-a` · worktree `../riverpod_core-a`

## What changed
- **Settings** `lib/core/storage/prefs_storage.dart`: `PrefsStorage` over `shared_preferences`. Typed keys in one place (`PrefKeys`): device settings `settings.themeMode`, `settings.locale`, `settings.onboardingSeen`; user-scoped keys use the `user.` prefix (`user.notificationsEnabled`). `clearUserScoped()` removes only `user.*`. `prefsStorageProvider` is keepAlive and async (awaits `SharedPreferences.getInstance()` once).
- **Secrets** `lib/core/storage/secure_storage.dart`: `SecureStorage` over `flutter_secure_storage`. Typed keys (`SecureKeys.accessToken`, `refreshToken`), `readAccessToken()`/`readRefreshToken()`, `clearAll()`. `secureStorageProvider` is keepAlive.
- **Database** `lib/core/storage/database/app_database.dart`: Drift `AppDatabase` with table `cache_entries` (key, payload, savedAt as integer millis, optional etag). Methods: `readCache`, `writeCache` (upsert), `deleteCache`, `deleteCacheSavedBefore` (expiry), `clearCache`. `AppDatabase.inMemory()` for tests. `appDatabaseProvider` is keepAlive, opens `driftDatabase(name: 'app_db')` and closes on dispose.
- **Logout wipe** `lib/core/storage/clear_user_data.dart`: `clearUserData({secure, prefs, database})` clears secrets, the cache table and user-scoped prefs; device settings stay.
- **Removed Hive**: `lib/core/local_services/**` (LocalStorage, Hive box), `lib/core/enum/constants.dart`; `hive_flutter` removed from `pubspec.yaml` and `pubspec.lock`. The `LocalStorage` init block is removed from `lib/main.dart` (init calls only).
- **info_service.dart**: the one `Constants.deviceInfo.name` reference is now the literal `'deviceInfo'` (approved by the Lead), and the constants import is dropped.
- **Fakes** (`test/helpers/`): `FakeSecureStorage` (in-memory map, overrides every method, so the platform keystore is never called); `fakePrefsStorage(initial)` (shared_preferences mock values). Both exported from `helpers.dart`.

- **Generated**: `prefs_storage.g.dart`, `secure_storage.g.dart`, `app_database.g.dart` next to their sources (the same convention as `app_config.g.dart`); committed.

## Decisions made
- Settings in prefs, secrets in secure storage, structured and cached data in Drift (D-004).
- `PrefKeys.userPrefix = 'user.'` marks user-scoped keys. Logout removes by prefix, so new user keys must use it.
- Cache expiry is a delete by `savedAt` (`deleteCacheSavedBefore`). The staleness decision (TTL) belongs to the SWR helper (C-16/C-07), not to the table.
- `savedAt` is stored as integer milliseconds UTC, not Drift's DateTime, so no precision is lost.
- `clearUserData` is a plain function taking the three stores, approved by the Lead; it is not a provider.

## Suggested follow-ups
- `AppDatabase.inMemory()` uses `NativeDatabase.memory()`, which needs the system SQLite on the test host (macOS ok). Check on CI before relying on it there.
- `driftDatabase` (production) and `FlutterSecureStorage` (platform) are not exercised by unit tests; they need a device or integration test.
- `FakePrefsStorage` is a function over the shared_preferences mock, not a subclass; tests that need a provider override use `prefsStorageProvider.overrideWithValue` with the returned instance.
- C-07/C-16 consume `AppDatabase.readCache`/`writeCache`/`deleteCacheSavedBefore`.
