## State rules in AsyncValueView
no data + loading = loading skeleton; no data + error = `ErrorState` (offline variant while connectivity is offline); data + `isEmpty` = `EmptyState`; data + (`isStale` | offline | failed reload) = banner above content; data + `hasPartialError` = `AppBanner` error row with retry (`onPartialRetry` or `onRetry`); data + loading = thin progress line overlaid at the top (no layout shift, hidden during a pull because `RefreshIndicator` shows itself); otherwise the builder. `onRefresh` wraps the body in `RefreshIndicator`; empty/error states are scrollable so they can be pulled. Coming back online runs `onRetry` once if the view shows an error or stale data. Needs a bounded height.
