## Deliberately KEPT
- `common.nativeName.{ar,en}`: zero references, but they are the labels a language picker needs. Owner decision below.
- `PrefsStorage.themeMode` / `setThemeMode` / `PrefKeys.themeMode`: nothing in lib reads or writes it yet, but tests assert it survives sign-out ("device setting kept"). Extension point for a theme switcher.
- `CacheStore.deleteSavedBefore`, `AppFormatters.dateLong/dateTime`, `relativeTime`, `ProgressStream`, `ExternalLinks.openMail/openPhone/openStore`, `ShareService.shareLink`, `ReviewService.maybeAskForReview`, notification service methods (`scheduleDaily/Weekly`, `showGroupSummary`, `requestProvisionalPermission`, `openSystemSettings`): template service APIs, test-covered, mostly named in README/DECISIONS/TASKS.
- `assets/fonts/.keep`: the folder is part of the documented layout (ARCHITECTURE.md); apps add fonts there.
- `AppToast`, `AppTooltip`, `AppSliverAppBar`, `PermissionRationaleDialog` and other design_system widgets used only by tests/showcase: rule 8, extension library.
- Golden PNGs: no orphan could be proven (names are built dynamically and file access times are unreliable here); all golden tests pass.

## For the owner to decide
1. Delete `common.nativeName.*` if no language picker is planned, or build the picker (`context.setLocale`) and use it.
2. The `themeMode` preference has no UI or consumer: add a theme switcher or drop the pref and its tests.
3. `ai-docs/ARCHITECTURE.md` line 65 lists `tool/check_l10n_keys`, which does not exist (ai-docs belongs to the Lead; not edited).
4. Possible orphan golden PNGs under `test/goldens/**` (for example variants such as `controls_light_en_x2.png`): proving it needs a run with a recording comparator; not done here.
