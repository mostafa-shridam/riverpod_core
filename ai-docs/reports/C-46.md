# C-46 — Storage and wiring leftovers after C-41

Worker A · branch `worker-a` · worktree `../riverpod_core-a`

## What changed
- **Rationale before the system prompt.** `bootstrap.dart` overrides `permissionRationalePresenterProvider` with `showPermissionRationale` (the design-system tear-off). Without it the permission flow skipped the explanation.
- **Typed settings, no generic-slot access for the three keys.** `PrefsStorage` already had `appLockEnabled`, `dismissedUpdateVersions` and `disabledNotificationChannels`. The callers now use them, with the same keys and the same stored encoding:
  - `AppLockController` (was `getStringList(appLockPrefKey)`), `appLockPrefKey` removed.
  - `NotificationSettingsController` (was `notificationDisabledChannelsKey`), constant removed.
  - `DismissedUpdates` in `features/app_gate` (was `prefKey`, the generic slot), constant removed. The soft update banner reads through it.
  - Grep: `getStringList` / `setStringList` with these keys now appear only inside the typed accessors in `prefs_storage.dart`. Other generic-slot callers (review, installation id, video favorites) are outside this list and unchanged.
- **`constants.dart` deleted.** `supportedLocales` and `translationsPath` moved to `lib/core/localization/app_locales.dart`. The three date formats (`dateFormat`, `atDateFormat`, `dateOnlyFormat`) had no users anywhere in `lib` or `test`, so they were dropped rather than moved. No behaviour changes.
- **Splash on a clock.** `StartupController` takes its minimum display time from `startupClockProvider` (a `DateTime Function()`, default `DateTime.now`). The sequence records a deadline when it starts and holds until the clock reaches it, polling every 20 ms. A clock already past the deadline does not wait.

## Decisions
- **The splash deadline is decided by the clock, not a timer.** A test clock that does not move keeps the splash held however long the event loop runs, so the test has no wall-clock assertion. The only real timer left is the 20 ms poll.
- **`supportedLocales` and `translationsPath` live in `core/localization/app_locales.dart`.** It is the natural owner: both are about the locales the app ships (D-035).
- **Dead date formats removed**, not moved, because nothing uses them. If a later task needs a date format, it adds one to `core/utils/formatting/`.

## Known limitations
- **The widget test does not go through the bootstrap container.** I tried running `bootstrap` inside `testWidgets` and pumping its container. The run failed with a `FlutterError.onError` assertion (bootstrap installs its own error handlers, and the test framework's pending-exception check fired before my failure message was visible). The presenter wiring itself is checked through the real bootstrap in the plain `test` above, so the rationale-before-prompt behaviour is tested through the same tear-off the bootstrap installs. Making the widget test run on the real container needs a bootstrap seam for error handlers; that is a follow-up for the Lead, not something I changed here.
- Golden and text-scale coverage for the rationale dialog is C-06/C-42 work and is not added here.
