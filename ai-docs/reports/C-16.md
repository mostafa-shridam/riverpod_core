## What changed
- `lib/core/storage/cache/cache_result.dart`: `CacheResult<T>(data, isStale, savedAt, error?)`.
- `lib/core/storage/cache/cache_policy.dart`: `Clock` typedef (`DateTime Function()`), `isExpired({savedAt, ttl, now})`, and `cacheKey(key, {userId})`. User-scoped keys are `user/<id>/<key>`; shared keys are `shared/<key>`.
- `lib/core/storage/cache/cached_repository_helper.dart`: `CachedRepositoryHelper` and a keep-alive `cachedRepositoryHelperProvider` built on `appDatabaseProvider` and `loggerProvider`.
  - `watch<T>({key, userId?, fetch, decode, encode, ttl})` returns `Stream<CacheResult<T>>`:
    1. if a cache entry exists, emits it with `isStale = expired(ttl)`;
    2. runs the fetch, writes the cache on success, and emits the fresh value (`isStale = false`);
    3. if the fetch fails with a cache, emits the cached value with `isStale = true` and the mapped `AppException`; with no cache, the stream errors with the mapped exception.
  - `read<T>` is a one-shot read that never fetches; it returns null on a miss.
  - `invalidate(key, {userId})` removes one entry; `clearAll()` removes every entry.
  - `fetch` returns a record `({value, etag?})`; the etag is stored with the entry.
- `lib/core/storage/cache/cached_repository_helper.g.dart`: generated for the provider, committed next to its source (D-003).

## Behaviour details
- **One fetch per key:** concurrent watchers of the same key share the running fetch. The shared fetch removes itself when it completes.
- **Invalidate during a fetch:** `invalidate` bumps a per-key version and drops the running fetch from the shared map. A fetch that finishes after invalidation does not write its value, so an outdated value cannot come back into the cache. Watchers started after invalidation start a new fetch.
- **Unreadable cache entry:** a payload that fails to decode is logged as a warning, deleted, and treated as a miss, so one bad row cannot break the screen.
- **Cache write failure:** the fresh value is still emitted; the failure is logged at error level with its stack trace. It is not swallowed silently.
- **Errors:** every fetch error goes through `mapError`, so the stream carries only `AppException`s.
- **No retries:** the helper does not retry fetches, and it does not add Riverpod provider retries (D-032).
- **Time:** the helper takes a `Clock`; tests inject a fixed clock and never read the real time.
