# C-11 — Router: typed routes, guards, shell, error page

Worker A · branch `worker-a` · worktree `../riverpod_core-a`

## What changed
- **Router** (`lib/app/router/app_router.dart`): `appRouterProvider` (keepAlive) builds the one `GoRouter` (D-016, D-005). Redirects are the pure `appRedirect` function. A `ValueNotifier` refreshes the router when the session or `onboardingSeen` changes. Unknown locations use `AppErrorPage`. `onboardingSeenProvider` reads `prefsStorageProvider`.
- **Typed routes** (`lib/app/router/routes.dart`, go_router_builder): splash, onboarding, login, a stateful shell with two branches (`/home`, `/more`), and `/items/:id`. All paths come from `AppPaths` (`lib/app/router/paths.dart`). `routeForDeepLink(type, id)` maps a payload to a typed route and returns null for unknown types.
- **Guards** (`lib/app/router/guards/app_redirect.dart`): startup → splash until session and onboarding are known; onboarding until seen; login until signed in; then the app. `/` goes to home.
- **Shell** (`lib/app/router/app_shell.dart`): `NavigationBar` with one stack per branch; reselecting a tab returns it to its first page. Labels come from `app_nav.*`.
- **Pages**: `lib/features/home/presentation/pages/home_page.dart` (moved from `home.dart`); `lib/app/startup/splash_page.dart`; `lib/app/router/app_error_page.dart` (uses design_system `ErrorState`); `lib/app/router/placeholder_pages.dart` (onboarding, login, more, item detail). The placeholders are temporary: C-17 and C-18 replace them.
- **Session stub** (`lib/core/auth/session_controller.dart`): `SessionStatus { unknown, signedOut, signedIn }`, `SessionController` (keepAlive). It consumes `SessionEvents.expired` from `lib/core/network` (an expiry signs out). `restore()`, `signIn()` and `signOut()` are the stub API for C-17.
- **App** (`lib/app/app.dart`): `MaterialApp.router` with the messenger key, locale from easy_localization (`context.locale`), the design_system themes, `routerConfig: appRouterProvider`, and the clamped text scale. The `ResponsiveBreakpoints` wrapper is removed, and so is the no-op `LifeCycleManager` wrapper (its file was deleted, since nothing else used it). Breakpoints come from `design_system/responsive` only.
- **Deep links** (`lib/core/helper/deep_link_helper.dart`): `handleRouteById(pyload:)` keeps its signature. It emits a `(type, id)` event on a broadcast stream, and the router maps it to a typed route. **Temporary bridge for C-20**: core cannot import `app/`, so the mapping happens in the router. The notification services are untouched.
- **Deleted**: `lib/core/router/**` (legacy `Routes`, mobile, iPad and web routing), `lib/core/services/app_router.dart`, `lib/features/home/presentation/home.dart`, `lib/core/services/life_cycle_manager.dart`.
- **Dependencies**: added `go_router_builder` 4.5.0 as a dev dependency (BSD-3, D-016; license file present in the pub cache). Removed `responsive_framework`, which nothing else imports (verified by grep).
- **Translations**: appended top-level `app_nav` {home, more, continue} to `ar.json` and `en.json`, approved by the Lead.
- **TASKS.md**: C-11 status set to REVIEW.
- **Generated**: `routes.g.dart`, `app_router.g.dart`, `session_controller.g.dart` next to their sources.

## Tests added
- `app_redirect_test.dart`: every redirect rule: unknown → splash; unseen onboarding; signed-out → login; signed-in leaves login and splash; any app location while signed in; `/` → home.
- `routes_test.dart`: each typed route's location equals its `AppPaths` constant; item id in the path; `routeForDeepLink` maps `myEvents` and ignores unknown types.
- `app_router_test.dart` (widget, real router and real session controller): new user → onboarding; signed out → login; signed in → home with the navigation bar; an expired session event → login; unknown location → error page; a deep link opens `/items/42` with the id shown.

## Decisions made
- Redirect rules are a pure function, so they are tested without a router.
- A deep link received while signed out is redirected to login and dropped. Keeping it for after sign-in is a follow-up (C-17 or C-20).
- `myEvents` is the only payload type kept from the old notification contract, and it maps to the item route.
- The shell has two branches (Home, More). "More" is a placeholder until a feature needs the tab.
- `SessionController` is a stub: its `restore()` moves unknown to signed-out. C-17 must replace it with a real token restore.
