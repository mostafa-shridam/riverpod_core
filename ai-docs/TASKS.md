# TASKS — the only task list

Statuses: READY → IN_PROGRESS·<worker> → REVIEW → CHANGES | DONE. `BLOCKED` while a dependency is not DONE.
Only the Lead sets CHANGES/DONE and assigns tasks. A worker works on exactly one task.
Two in-progress tasks never share a file; the Lead checks the `Files:` lists before assigning.
Every task: follow the Definition of Done in CLAUDE.md, write `ai-docs/reports/C-xx.md`, commit by path as "C-xx: …".
New package: must be approved in DECISIONS.md or named in the task; record the exact resolved version and license in the report.
Architecture and paths: ARCHITECTURE.md (target tree). Old paths in existing code (`lib/core/themes`, `lib/core/widgets`, `lib/core/router`, `lib/core/remote_services`, `lib/core/local_services`, `lib/main.dart`) are removed by the tasks below.
